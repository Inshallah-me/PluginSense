# PluginSense

Lightweight CS2 plugin made for double injecting with [GameSense](https://gamesense.pub).

## Features

- Visuals: weather, wind, wetness, bloom, gamma, depth of field, motion camera, velocity, keystrokes
- Changer: weapon model changer, name changer, clantag
- Chat: chat spammer, kill say
- Other: lobby spoof, damage log, Fortnite damage indicators

## Build

- Visual Studio 2022 (MSVC 14.44), Release x64
- Open `PluginSense.sln` and build, output: `bin\x64\Release\PluginSense.dll`
